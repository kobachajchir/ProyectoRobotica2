# Robot recolector — propuesta de montaje

AFR2-20261027-01, 27/10/2026. Distribucion nominal para discutir la integracion
del brazo v02 y una bandeja sobre el auto. [Dibujo superior/lateral editable](propuesta_montaje.svg).

El SVG es fuente propia, editada a mano, sin herramientas generativas ni assets
externos. No es un plano de fabricacion ni un ensamble nativo de Fusion. Se
conservan los maestros independientes del auto y del brazo, sin modificarlos.

La Web usa un rig simplificado articulado, con la cadena de la v02 y una base
propuesta a90 mm sobre el suelo. La bandeja de118 ×118 mm sobresale hacia
delante/derecha y requiere una extension de soporte; no se acredita estabilidad.
El sensor virtual bajo a45 mm no modifica la ubicacion del HC-SR04 del GLB.
