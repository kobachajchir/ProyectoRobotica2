# Modelo completo del auto

Ubicación del ensamblaje editable del vehículo: chasis, motores, ruedas Mecanum, electrónica, batería, soporte/pieza nueva y envolventes del cableado según los datos que se aporten.

Usar referencias relativas a ../componentes y ../pieza-nueva; registrar la revisión y procedencia de cada insumo incorporado. Los archivos de ../../reference/supplied son referencias conservadas, sin confirmar equivalencia al auto. El GLB histórico de AutoMicro tampoco representa este vehículo.

Estado: no hay ensamblaje nuevo ni dimensiones verificadas. Exportaciones para visor Web, revisión o fabricación irán en ../../exports; su uso en Web requerirá una adaptación explícita y trazable.
