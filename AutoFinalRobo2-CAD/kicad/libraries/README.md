Aquí se versionarán símbolos, huellas y modelos propios o adaptados, con autoría y procedencia por archivo. Conservar tablas de bibliotecas del proyecto y referencias relativas; evitar rutas absolutas de una instalación local.

No copiar aquí toda la biblioteca estándar de KiCad. Las dependencias sin cambios que puedan recuperarse van en ../../vendor o ../../.downloads, ignoradas, con versión/origen/licencia/checksum y recuperación en ../../reference/DEPENDENCIAS.md. Un recurso modificado o sin origen recuperable se conserva y documenta como fuente/insumo.
