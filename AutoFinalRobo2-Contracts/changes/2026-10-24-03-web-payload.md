## Comandos y protección de tamaño

Desde `D:/ProyectoRobotica2/AutoFinalRobo2-Web`:

- `npm run build`: compila el perfil `full` para PC y empaqueta localmente.
  Incluye la malla antigua y solo los dos activos del decodificador WASM.
- `npm run build:esp`: compila el perfil `esp`, empaqueta y promueve a
  `../AutoFinalRobo2-ESP/data/dist`. No crea una imagen de filesystem ni flashea.
- `npm run package:littlefs`: reempaqueta el `dist` actual, leyendo su perfil
  desde `.afr2-build.json`; ese marcador no es un activo HTTP.
- `npm run copy:esp`: acepta únicamente un paquete `esp` dentro de presupuesto.
  Conserva el formato `afr2-littlefs-manifest-1`; añade datos de perfil/tamaño
  compatibles con el lector ESP existente. `image/webp` ya estaba soportado.

Presupuesto de software: **900 KiB (921.600 bytes)**. Estimación conservadora:

Solo se retiraron del destino los `.gz` obsoletos gestionados por el manifiesto
